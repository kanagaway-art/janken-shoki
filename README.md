# ①課題名
じゃんけんアプリ

## ②課題内容（どんな作品か）
- ボタンをクリックして、コンピュータとじゃんけん対戦ができるアプリです。

## ③アプリのデプロイURL
- https://kanagaway-art.github.io/janken-shoki/

## ④アプリのログイン用IDまたはPassword（ある場合）
- ID: 今回なし
- PW: 今回なし

## ⑤工夫した点・こだわった点
- グー・チョキ・パーのボタンをクリックすると、コンピュータがランダムに手を出すようにしました。
- 自分の手に対して「勝ち・負け・あいこ」を自動で判定して表示するようにしました。

## ⑥難しかった点・次回トライしたいこと（又は機能）
- `Math.random()` を使った乱数でコンピュータの手を決めるところが難しかった。
- 次回は勝敗の演出や、スコアを数える機能を付けてみたい。

## ⑦フリー項目（感想、シェアしたいこと等なんでも）
- [感想] 本当に仕事が忙しすぎて、ついていけるか心配です。

---

## 遊び方
1. 公開URL（上記③）を開く、またはこのフォルダの `index.html` をブラウザで開く。
2. **グー / チョキ / パー** のいずれかをクリックする。
3. コンピュータの出した手と、勝敗（勝ち・負け・あいこ）が表示されます。

- HTML / CSS / JavaScript
